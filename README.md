IOPn Builder Hub ⚡

A lightweight on-chain builder activity, community engagement, and DeFi experimentation hub built on OPN Chain.

Overview

IOPn Builder Hub combines builder participation, community interaction, and DeFi tools into a single on-chain experience.

The project is designed to explore verifiable on-chain activity while providing simple tools for builders to interact, contribute, and experiment within the OPN ecosystem.

---

Features

⚡ Builder Hub

- Daily Check-In
- Ship Tracking
- Builder Statistics

📝 Community

- On-Chain Guestbook

💰 DeFi Lab DEX

- Token Factory
- Pool Factory
- Add Liquidity
- OPN → Token Swap
- Token → OPN Swap
